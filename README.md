# 리뷰 형태소 분석기 설치·사용 안내

**[⬇ 최신 버전 설치 파일 내려받기](https://github.com/ethen-carter/review-analyzer-releases/releases/latest/download/review-analyzer-setup.exe)**

## 1. 내려받기

아래 주소를 누르면 설치 파일이 바로 내려받아집니다. 항상 최신 버전이 내려옵니다.

https://github.com/ethen-carter/review-analyzer-releases/releases/latest/download/review-analyzer-setup.exe

- 파일 이름은 `review-analyzer-setup.exe`이며 약 165MB입니다.
- 브라우저가 "흔히 다운로드되는 파일이 아닙니다"라고 경고하면 **[유지]** 를 눌러 주세요.

## 2. 설치하기

1. 받은 파일을 더블클릭합니다.
2. 파란 **"Windows의 PC 보호"** 창이 뜨면 **[추가 정보]** 를 누른 뒤 **[실행]** 을 누릅니다.
   새로 나온 프로그램이라 Windows가 확인 차원에서 띄우는 창이며, 한 번만 하면 됩니다.
3. 설치 창에서 **[설치]** 를 누르면 30초쯤 뒤 끝납니다. 관리자 권한은 필요 없습니다.
   바탕화면과 시작 메뉴에 **리뷰 형태소 분석기** 아이콘이 생깁니다.
4. 마지막 화면에서 **[마침]** 을 누르면 프로그램이 바로 켜집니다.

설치 파일은 다 쓰고 나면 지워도 됩니다. 다음부터는 **바탕화면 아이콘**으로 켜세요.

## 3. 처음 실행하기

1. **설치 후 처음 켤 때는 10~20초쯤 걸립니다**(백신이 새 파일을 한 번 검사합니다). 그다음부터는 3~4초면 켜집니다.
2. **제품 인증** 창에 받은 제품 코드를 입력하고 **[인증]** 을 누릅니다.
   코드는 `RVMA-XXXX-XXXX-XXXX` 모양입니다. 처음 인증할 때는 인터넷이 필요합니다.
3. 인증되면 바로 메인 화면이 열립니다. 화면 위쪽에 **사용 종료일과 남은 기간**이 표시됩니다.

## 4. 사용하기

- **[리뷰 파일 열기]** 를 누르거나, 쿠팡·스마트스토어에서 내려받은 리뷰 파일(CSV·XLSX)을 창에 끌어다 놓으세요.
- 분석이 끝나면 대시보드에서 감성 분포·키워드·속성별 만족도를 보고,
  **[HTML 리포트]**·**[마케팅 액션팩]**·**[결과 내보내기]** 로 저장할 수 있습니다.
- 저장 폴더는 오른쪽 위 **톱니바퀴(환경설정)** 에서 바꿀 수 있습니다.

## 5. 업데이트

새 버전이 나오면 프로그램을 켤 때 **"새 버전이 있습니다"** 창이 뜹니다.

- **[지금 업데이트]** 를 누르면 자동으로 내려받아 설치하고 다시 켜집니다. 1분 정도 걸리며,
  그동안 **설치 진행 창**이 잠깐 보입니다. 다시 켜질 때까지 기다려 주세요.
- 바쁘면 **[나중에]** 를 눌러도 됩니다. 다음에 켤 때 다시 알려 드립니다.
  꼭 필요한 업데이트일 때는 이 버튼이 보이지 않습니다.
- 자동 업데이트가 안 되면 **[직접 다운로드]** 로 새 설치 파일을 받아 실행하면 됩니다. 설정과 인증은 그대로입니다.

## 6. 인터넷이 없을 때

한 번 인증한 PC는 **인터넷 없이도 7일 동안** 쓸 수 있습니다.
7일이 지나면 인터넷에 연결한 상태로 한 번 켜 주세요. 자동으로 다시 확인됩니다.

## 7. 자주 묻는 질문

**예전에 받은 `review-analyzer.exe` 파일은 어떻게 하나요?** (1.1.0 이하를 쓰시던 분)
업데이트하면 설치 창이 **한 번** 뜹니다. **[설치]** 를 누르면 그다음부터는 바탕화면 아이콘으로 켜면 됩니다.
예전 파일을 눌러도 설치된 프로그램이 열리므로 그대로 두셔도 되고, 지우셔도 됩니다.

**프로그램을 지우고 싶어요.**
Windows **설정 → 앱 → 설치된 앱**에서 **리뷰 형태소 분석기**를 제거하면 됩니다. 인증 정보는 PC에 남아 있어 다시 설치하면 코드 입력 없이 쓸 수 있습니다.

**업데이트 직후 처음 켤 때 오류 창이 떠요.**
방금 바뀐 파일을 백신이 검사하는 중이라 생길 수 있습니다. 창을 닫고 **한 번 더 실행**하면 정상으로 켜집니다.

**"허용된 기기 수를 초과했습니다"라고 나와요.**
코드마다 쓸 수 있는 PC 수가 정해져 있습니다. 다른 PC를 정리했거나 PC를 바꾸셨다면 문의처로 알려 주세요.

**PC를 바꿨어요.**
새 PC에 프로그램을 받아 같은 코드를 입력하면 됩니다. 기기 수가 모자라면 문의처로 알려 주세요.
인증 정보는 PC마다 따로라서, 예전 PC의 파일을 복사해 와도 인증은 다시 해야 합니다.

**"서버에 연결할 수 없습니다"라고 나와요.**
인터넷 연결을 확인한 뒤 다시 시도해 주세요. 회사 보안 프로그램이 막는 경우도 있습니다.

**"사용이 중지된 코드" 또는 "만료된 코드"라고 나와요.**
사용 기간이 끝났거나 코드가 정지된 상태입니다. 문의처로 연락 주시면 연장해 드립니다.
